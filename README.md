# 쿠팡 소싱 신호등 — 설치 파일

이 저장소는 **설치 파일과 자동 업데이트 정보만** 올리는 곳입니다(소스코드 없음).

## 설치 (윈도우)
1. 오른쪽 **Releases**에서 최신 `CoupangSignal-Setup-x.y.z.exe`를 내려받습니다.
2. 실행합니다. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다(코드 서명 전이라 처음 한 번 뜹니다).
3. 바탕화면의 **쿠팡 소싱 신호등**으로 실행합니다.

## 사용 조건
로켓그로스 대시보드 계정 로그인 + 승인된 수강생 판매자 계정(Wing)이 필요합니다.

## 업데이트
프로그램이 켜질 때 새 버전을 자동으로 내려받고, 위쪽 **다시 시작해 업데이트** 버튼이나 다음 종료 때 설치됩니다.

## 로켓그로스 요금표 (`rg-fees.json`)
앱이 켜질 때 이 파일을 읽어, 앱에 들어 있는 것보다 `version`이 크면 이것으로 입출고비·배송비를 계산합니다.
요금이 바뀌면 이 파일을 고치고 `version`을 1 올리면 앱 업데이트 없이 반영됩니다. (VAT 별도·단품 1개 기준)
